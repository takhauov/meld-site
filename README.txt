==========================================================
САЙТ MELD — как устроен и как править
==========================================================

СТРУКТУРА ПАПКИ

  build.js              сборщик, запускается одной командой
  README.txt            этот файл

  src/layout.html       ОБЩИЙ КАРКАС: шапка, подвал, стили, скрипты.
                        Правится ОДИН раз для всего сайта.
  src/pages/            содержимое страниц, без шапки и подвала
      index.html            главная
      catalog.html          витрина каталога
      catalog-airless.html  окрасочные аппараты
      catalog-spotter.html  споттеры

  assets/               картинки (webp)

  docs/                 ГОТОВЫЙ САЙТ — то, что уходит на хостинг.
                        Создаётся сборщиком, руками не правится.


==========================================================
КАК ПРАВИТЬ
==========================================================

Телефон, меню, подвал, стили — везде сразу:
    откройте src/layout.html, поправьте, запустите сборку

Текст одной страницы:
    откройте нужный файл в src/pages/, поправьте, запустите сборку

Новая картинка:
    положите файл в assets/, впишите путь в разметку
    например: <img src="assets/новое-фото.webp" ...>

СБОРКА — одна команда в папке сайта:

    node build.js

После неё в docs/ лежит готовый сайт. Проверить локально —
открыть docs/index.html двойным щелчком.


==========================================================
ВАЖНО ПРО ЛОКАЛЬНЫЙ ПРОСМОТР
==========================================================

Картинки лежат отдельными файлами, поэтому HTML нельзя
открывать в одиночку — рядом должна быть папка assets.
Открывайте именно docs/index.html, не перетаскивайте
файл в другое место.


==========================================================
НАЧАЛО СТРАНИЦЫ: ПАРАМЕТРЫ
==========================================================

Каждый файл в src/pages/ начинается с четырёх строк
и разделителя из трёх дефисов:

    title: заголовок вкладки и строка в поиске, до 60 знаков
    description: описание для выдачи, 150-160 знаков
    url: имя файла (у главной пустое)
    ---

Ниже — обычная разметка. Всё, что до "---", в страницу
не попадает, это служебные данные.


==========================================================
ПУБЛИКАЦИЯ
==========================================================

1. Купить домен и хостинг для статических сайтов
   (подойдёт любой самый простой тариф).
2. Загрузить ВСЁ содержимое папки docs/ в корень сайта.
3. Проверить, что meld.ru открывает index.html.

Бесплатные варианты хостинга под такой сайт:
GitHub Pages, Netlify, Cloudflare Pages. Домен
подключается к любому из них.

В build.js в самом начале есть строка

    const DOMAIN = 'https://meld.ru';

Замените на реальный домен до публикации: из него
собираются sitemap.xml, robots.txt и адреса в мета-теги.


==========================================================
ЧТО СБОРЩИК ДЕЛАЕТ САМ
==========================================================

- вставляет шапку и подвал в каждую страницу
- прописывает title, description, canonical и Open Graph
- на внутренних страницах превращает ссылки вида #контакты
  в index.html#контакты, чтобы меню работало со всех страниц
- копирует папку assets
- генерирует sitemap.xml и robots.txt
- останавливается с ошибкой, если в странице забыт
  обязательный параметр или осталась незаполненная метка


==========================================================
ЧЕГО НА САЙТЕ ПОКА НЕТ
==========================================================

- favicon (иконка вкладки)
- страница 404
- реальные телефон, адрес, мессенджеры
- ссылка на политику обработки персональных данных
- юридический адрес ИП
- фото первого экрана без надписи WELD на корпусе
- фото и характеристики споттера
- три кадра в блок «Решения» на главной
